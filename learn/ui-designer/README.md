## 📋 前置知识

- ✅ 了解基本的前端术语（组件、属性、样式等）

## 💡 阅读建议

本路径专为 UI 设计师设计，会避免深入的代码实现细节，
重点讲解**设计原理**、**Token 体系**、**组件规范**和**设计协作**。

遇到代码示例时，重点关注**配置项的含义**而非语法。
